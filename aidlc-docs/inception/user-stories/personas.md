## P1. 러너 (Runner) — 지역 러닝 사용자

| 항목 | 내용 |
|---|---|
| **이름/유형** | 러너 (일반 사용자) |
| **역할** | 전라도 지역에서 러닝 코스를 달리거나 직접 만들고, 러닝 후 주변 먹거리·시설을 찾는 모바일 앱 사용자 |
| **플랫폼** | 모바일 앱 (iOS/Swift + TypeScript 혼용 뷰) |
| **인증 방식** | 소셜 로그인 (카카오 / 애플) |

### 목표 (Goals)
- 내 지역(전라도)에 맞는 러닝 코스를 쉽게 찾아 달리고 싶다
- 원하는 경로를 직접 만들어 코스로 저장하고 싶다
- 달린 기록(거리/시간/경로)을 남기고 다시 보고 싶다
- 러닝이 끝난 뒤 도착지 근처에서 먹을 곳과 편의시설을 추천받고 싶다
- 믿을 만한 가게(모범음식점/착한가격업소)를 구분해서 보고 싶다

### 동기 (Motivations)
- 운동 습관 형성 및 지역 탐방
- 러닝 후 보상(먹거리)과 편의(화장실/약국 등) 정보 확보

### 불편함 (Pain Points)
- 지역에 특화된 러닝 코스 정보를 찾기 어려움
- 러닝 후 근처에 뭐가 있는지 일일이 검색해야 함
- 믿을 수 있는 가게 구분이 어려움

### 기술 수준 (Tech Proficiency)
- 일반 모바일 앱 사용자 수준. 소셜 로그인에 익숙함

### 주요 사용자 여정 (Primary Journey)
소셜 로그인 → 코스 탐색(공식 코스) 또는 코스 직접 생성 → 러닝(클라이언트 추적) → 완료 기록 저장 → 도착지 반경 1km 먹거리/편의시설 추천 확인
