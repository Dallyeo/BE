# Feature Inventory (화면별 백엔드 매핑) — Dallyeo

> 출처: 사용자 노션 정리 (백엔드 중점). 프론트 화면(View) 기준으로 백엔드가 제공해야 할 데이터/기능을 정리.
> ⚠️ 이 문서는 **초안**이며 일부 항목은 회의 후 확정 예정. (특히 V14 업적)

범례: 🆕 = 기존 요구사항/스토리에 없던 신규 백엔드 항목, ❓ = 회의/확인 필요

---

## V1. 온보딩
- 기본 정보 입력: **키, 체중, 성별** 저장 🆕
- 기본 정보 **생략 가능**(온보딩 건너뛰기) → 신체정보는 nullable
- **백엔드**: 사용자 프로필에 신체정보(height, weight, gender) 저장 API. 최초 로그인 후 온보딩 흐름
- 관련: 소셜 로그인(US-AUTH-1) 이후 단계

## V2. 메인뷰
- **지역별 추천 코스** 데이터 (코스 설명 + 지도 경로용) → courses.json 기반
- **지역 데이터** 필요 🆕 (지역 목록/구분 — 군산/전주 등)
- 로그인 상태는 프론트가 관리
- **백엔드**: 지역별 코스 목록 조회, 지역 목록 조회

## V3. 지도뷰
- 현재 위치 기반 **관광지 / 음식점 / 편의시설** 데이터
- **마커/장소 선택 시 장소 상세** 데이터
- **추천 관광지** (시 단위 관광지)
- **추천 음식점** (시 단위 음식점)
- **백엔드**: 좌표 기반 주변 장소 조회, 장소 상세, 시(region) 단위 추천 목록
- 관련: US-REC-1/2/3 (단, "시 단위 추천"은 근접(반경) 추천과 별개 개념 ❓)

## V4. 검색뷰
- 입력 검색어 기반 **검색 결과** 데이터
- **유사 검색어** 데이터 🆕
- **최근 검색어** 리스트 🆕 (사용자별 저장 필요 → 인증 연동 ❓)
- **백엔드**: 장소 검색(`GET /places/search`), 유사 검색어 추천, 최근 검색어 저장/조회
- 관련: 계약서의 `GET /places/search` (프론트 기구현)

## V5. 검색 결과뷰
- 검색어에 맞는 결과 리스트
- 유사 검색 결과 리스트
- **백엔드**: 검색 결과 페이징/목록 (V4와 동일 API 계열)

## V6. 위치 정보뷰
- 검색어에 맞는 결과 리스트 / 유사 결과 리스트
- ❓ V5와 내용이 거의 동일 — 차이 확인 필요 (지도상 위치 표시용인지)
- **백엔드**: 장소 상세(`GET /places/{id}`) 활용 추정

## V7. 경로 수정뷰
- 출발지 / 경유지 / 도착지 + **Tmap API로 생성된 JSON** 데이터가 올 가능성 높음 → **그걸 저장**
- **백엔드**: 사용자 생성 코스 저장 (프론트가 Tmap으로 만든 경로 JSON 수신). 백엔드는 Tmap 호출 안 함 (기존 결정 일치)
- 관련: US-COURSE-3, courses.json 구조 재사용

## V8. 코스 확인뷰
- 경로 수정뷰에서 저장한 **지도 마커 JSON** + 근처 **편의시설/관광지 좌표** 데이터
- **백엔드**: 저장된 코스 조회 + 경로 주변 시설/관광지 조회
- 관련: US-COURSE-2, US-REC-3

## V9. 코스 진행뷰
- (내용 미기재 — 러닝 실행 중 화면, 클라이언트 GPS 추적. 백엔드는 완료 데이터만 수신)
- 관련: US-RUN-1 (완료 후 저장)

## V10. 완주 결과뷰
- 완료한 러닝 데이터
- **코스 완주율** 데이터 🆕
- 완료한 코스 경로 데이터
- **완료한 러닝 통계** 데이터 🆕
- **공유용 결과** 데이터 🆕
- 완료 지점 **근방 500m** 관광지/카페/편의시설/음식점 데이터
  - ⚠️ 이전에 먹거리 추천을 **1km**로 정했는데 여기선 **500m** — 반경 기준 통일 필요 ❓
- **백엔드**: 러닝 완료 저장 + 완주율 계산 + 통계 + 완료 지점 근접 장소 조회

## V11. 기록뷰
- **기간별 통계** 데이터 🆕
- **백엔드**: 사용자 러닝 기록 기간별 집계/통계
- 관련: US-RUN-2 (조회) + 통계 확장

## V12. 기록 상세뷰
- 기록뷰에서 선택한 기록의 **상세** 데이터
- **백엔드**: 러닝 기록 상세 조회 (US-RUN-2)

## V13. 설정뷰
- **프로필 사진** 🆕 (업로드/저장 → 이미지 스토리지 필요 ❓)
- **키/체중/성별 수정** (V1 신체정보 수정)
- 이용약관 / 개인정보 처리방침 (정적 콘텐츠 ❓ 백엔드 제공 여부)
- **로그아웃** (토큰 무효화)
- **계정 삭제** 🆕 (회원 탈퇴)
- **백엔드**: 프로필 조회/수정, 프로필 이미지, 로그아웃, 계정 삭제

## V14. 업적뷰 ❓ (미확정 — 회의 필요)
- 업적 목록 / 업적 상세 데이터
- 세부 사항 미정 → **논의 후 정의**
- **백엔드**: (보류) 업적 도메인

---

## 🔑 신규로 드러난 백엔드 도메인 (기존 스토리에 없던 것)
1. **사용자 프로필 / 신체정보** (키·체중·성별, 프로필 사진) — V1, V13
2. **지역(Region) 데이터** — V2, courses.json `region`
3. **검색 부가기능** — 유사 검색어, 최근 검색어(사용자별) — V4/V5
4. **통계 / 완주율** — 기간별 통계, 코스 완주율, 공유용 결과 — V10/V11
5. **계정 관리** — 로그아웃, 계정 삭제 — V13
6. **업적(Achievement)** — V14 (미확정)
7. **정적 콘텐츠** — 이용약관/개인정보 처리방침 (제공 방식 미정)

## ⚠️ 확정 필요한 충돌/미결 사항 (회의 안건)
- **근접 추천 반경**: 먹거리 1km(기존) vs 완주 결과 500m(V10) — 통일 또는 화면별 구분
- **"시 단위 추천"** vs **"반경 근접 추천"**: 두 방식 병존 여부 (V3)
- `searchOption` / `declaredCategory` vs `measuredCategory` 의미 (courses.json)
- V5 vs V6 차이
- 프로필 이미지 저장 방식 (외부 스토리지/S3 등)
- 이용약관·개인정보 처리방침 제공 주체(백엔드 API vs 앱 정적)
- V14 업적 전체
- 최근 검색어: 사용자별 서버 저장 vs 클라이언트 로컬 저장
