# 데이터 업로드 폴더 (data)

> **용도**: 사용자가 **직접 데이터 파일을 올리면**, 그걸 확인해서 우리가 실제로 쓸 데이터/필드를 정리하는 공간입니다.
> 공공데이터포털 API 응답 샘플, 파일 데이터(csv/json/xlsx), 고정 코스 등 원본 데이터를 여기에 넣어주세요.

## 폴더 구조

| 폴더 | 넣을 것 |
|---|---|
| `courses/` | 고정 코스 폴리라인 데이터 (예: `courses.json`) |
| `public-data-samples/` | **공공데이터포털 API 응답 샘플** (JSON/XML). 어떤 API인지 파일명이나 메모로 구분 |
| `file-data/` | 파일 기반 데이터 (공중화장실, 가로등, 약국, 모범음식점, 착한가격업소 등 — csv/json/xlsx) |

## 올릴 때 팁
- 파일명에 **출처/내용**을 담아주세요 (예: `gunsan-model-restaurant.csv`, `publicdata-toilet-sample.json`)
- 공공데이터 API는 **실제 응답 1건 샘플**만 있어도 필드 파악에 충분합니다
- 어떤 API/데이터인지 헷갈리면 이 README 하단 "업로드 로그"에 한 줄 남겨주세요

## 이걸로 할 작업 (다음 단계)
1. 올려주신 공공데이터 응답을 확인해 **실제 필드/타입**을 파악
2. `api-spec-draft.md`의 장소(Places) 응답 스키마와 **비교** → 우리가 쓸 필드 확정
3. 파일 데이터(모범음식점/착한가격업소 등)의 매칭 키 확인 → 배지 로직 설계
4. 정리 결과로 API 명세를 v1.0으로 갱신
