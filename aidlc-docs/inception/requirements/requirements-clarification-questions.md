## Question 8 — 러닝 코스의 출처(누가 만드는가)

B) 사용자들이 만들어 공유한 코스만
C) 관리자 공식 코스 + 사용자 공유 코스 둘 다

운영자가 넣어둔 데이터가 맞는것 같아.

## Question 12 — 먹거리/주변 시설 데이터 출처
먹거리·편의시설·관광지·음식점 정보는 어디서 가져오나요?

A) 외부 지도/장소 API (예: 카카오맵, 네이버, 공공데이터포털)
B) 운영자가 직접 등록/큐레이션한 자체 DB
C) 외부 API + 자체 큐레이션 혼합
X) Other (please describe after [Answer]: tag below)

[Answer]: A 공공데이터 포털에서 가져올거야. 다른 API가 추가될 가능성도 있긴한데 추가되면 말해줄께
행정안전부 전국공중화장실 데이터, 군산시 가로등 현황, 군산시 약국 현황도 추가할 가능성이 있어 이거는 아마도 파일 데이터를 쓸거야.

## Question 13 — 먹거리 추천 기준
러닝 후 "먹거리 추천"은 무엇을 기준으로 하나요? (여러 개면 X에 나열)

A) 코스 도착 지점(또는 경로) 주변 근접성 위주
B) 근접성 + 사용자 취향/카테고리(한식/카페 등)
C) 근접성 + 소모 칼로리 기반 추천
D) 근접성 + 평점/인기 위주
X) Other (please describe after [Answer]: tag below)

[Answer]: A - 먹거리 추천은 좀 어렵긴한데 이건 나중에 로직을 수정한다 치고, 나중에 소모 칼로리 기반으로 할 수도 있기한데 이건 좀 애매해서 우선 은 A로
지금은 간단하게 도착 지점 근처에서 공공 데이터 포털 API, 
군산시 모범음식점, 착한 가격업소 공공데이터 파일로 저장을 해둔 파일에서 모범음식점, 혹은 착한 가격 업소인 가게들은 뱃지를 추가할 예정
