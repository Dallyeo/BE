# 인증 분류 (Auth Classification) — Dallyeo

> **정책**: **공개 브라우징 허용** — 조회(코스/장소/지역)는 비로그인 가능, **개인 데이터·소유 리소스·변경(mutation)은 토큰 필요**.
> **보안 원칙(Security Baseline SECURITY-08)**: **deny by default** — 기본은 🔒, 공개(🌐)는 아래에 **명시적으로 나열 + 사유**.
> 범례: 🔒 = 토큰 필요(`Authorization: Bearer`) · 🌐 = 공개(토큰 불필요)

---

## 1. 공개(🌐) 엔드포인트 — 명시적 예외 목록

모두 **읽기 전용(GET)** 또는 **토큰 발급 전 인증 흐름**이며, **개인 식별 데이터 없음**.

| 엔드포인트 | 화면 | 공개 사유 |
|---|---|---|
| `POST /auth/login/{provider}` | 로그인 | 토큰 발급 이전 단계 → 토큰 요구 불가 |
| `POST /auth/refresh` | (공통) | Access Token 만료 시 Refresh Token(본문)으로 재발급 |
| `GET /regions` | V2 | 지역 목록(군산/전주) — 비개인 참조 데이터 |
| `GET /courses` | V2 | 공식 코스 목록(카탈로그) — 비개인, 공개 브라우징 |
| `GET /courses/{id}` | V2/V8 | 코스 상세(경로/거리) — 비개인 카탈로그 |
| `GET /places/search` | V4/V5 | 키워드 장소 검색(TourAPI) — 비개인 외부 관광 데이터 |
| `GET /places` (지역기반 목록) | V3 | 지역 장소 목록(TourAPI) — 비개인 |
| `GET /places/nearby` (반경) | V3/V8/V10 | 좌표 반경 주변 장소(TourAPI) — 비개인 |
| `GET /places/{id}` (상세) | V3/V5/V6 | 장소 상세(TourAPI 조합 + 배지) — 비개인 |

> 배지(모범음식점/착한가격업소)는 공개 장소 응답에 포함 — 공개 참조 데이터.

---

## 2. 보호(🔒) 엔드포인트 — 기본값(deny by default)

**개인 데이터 / 소유 리소스 / 변경 작업**은 전부 토큰 필요.

| 엔드포인트 | 화면 | 보호 사유 |
|---|---|---|
| `POST /auth/logout` | V13 | 본인 토큰 무효화 |
| `GET /users/me` | V13 | 본인 프로필 조회 |
| `PATCH /users/me` | V1/V13 | 온보딩 신체정보 저장 + 설정 수정(본인) |
| `DELETE /users/me` | V13 | 계정 삭제(본인) |
| (프로필 사진 업/삭제) | V13 | 본인 리소스 변경 — ⏸️ 저장방식 보류 |
| `POST /courses` | V7 | 사용자 생성 코스 저장(소유) |
| `POST /runs` | V9/V10 | 본인 러닝 기록 저장 |
| `GET /runs` | V11 | 본인 기록 목록 |
| `GET /runs/{id}` | V12 | 본인 기록 상세(타인 → 403/404) |
| `GET /runs/stats` | V11 | 본인 기간별 통계 — ⏸️ 항목 보류 |

## 3. 화면별 인증 요약 (혼합 화면 주의)

한 화면이 공개/보호 엔드포인트를 **동시에** 호출할 수 있음.

| 화면 | 호출 성격 |
|---|---|
| V1 온보딩 | 🔒 (신체정보 저장) — 로그인 직후 |
| V2 메인 | 🌐 (지역/코스 목록) |
| V3 지도 | 🌐 (장소 목록/주변/상세) |
| V4·V5 검색 | 🌐 (키워드 검색/상세) |
| V6 위치정보 | (배제) |
| V7 경로수정 | 🔒 (코스 생성 저장) |
| V8 코스확인 | 🌐 (코스 상세 + 주변 장소) |
| V9 코스진행 | (백엔드 없음) |
| V10 완주결과 | 🔒 (기록 저장) + 🌐 (주변 장소) |
| V11 기록 | 🔒 (기록 목록/통계) |
| V12 기록상세 | 🔒 (기록 상세) |
| V13 설정 | 🔒 (프로필/로그아웃/탈퇴) |
| V14 업적 | (보류) |

---

## 4. 구현 반영 (설계 시)
- **필터 정책**: Spring Security 등에서 **모든 경로 인증 요구(deny by default)** 후, §1 공개 목록만 `permitAll` 화이트리스트로 예외.
- **소유권 검증**: 🔒 리소스(runs 등)는 토큰의 사용자 ID와 리소스 소유자 일치 검증 → 불일치 403/404.
- **공개 GET도 레이트리밋/캐시** 권장(TourAPI 프록시 부하 고려).
- 🌐 목록은 향후 개인화(선택적 인증) 필요 시 optional-auth로 확장 가능.
