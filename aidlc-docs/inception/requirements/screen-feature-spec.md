# 화면별 필요 기능 정리 (Screen Feature Spec) — Dallyeo

> **용도**: 각 화면(View)에서 **필요한 기능**을 직접 적는 문서입니다.
> 여기에 적어주시면 그걸 기반으로 백엔드 기능/스토리/API를 정리합니다.
> 자유롭게 쓰시고, 모르면 비워두거나 `?`로 두세요.

## 작성 가이드 (한 화면당 아래 항목)
- **목적**: 이 화면이 사용자에게 무엇을 하는 화면인지 한 줄
- **필요 기능**: 화면에서 동작해야 하는 기능들을 불릿으로 (사용자 관점 OK)
- **필요 데이터**: 백엔드에서 내려줘야 할 데이터/값 (아는 만큼)
- **연동/비고**: 외부 API·다른 화면과의 관계·미결 질문 등
- **상태**: `초안` / `확정` / `보류(회의필요)` 중 표기

> 범례: 🆕 신규 기능 · ❓ 확인/논의 필요 · 🔗 다른 화면·API와 연관

## V1. 온보딩
- **목적**: 사용자가 처음 회원가입 및 로그인을 진행했을 때 사용자 정보를 받는 페이지
- **필요 기능**:
  - 기본 정보 입력
  - 기본 정보 입력 건너뛰기(즉 데이터를 안받을 수 있다.)
- **필요 데이터**:
  - 키, 체중, 성별 데이터
- **연동/비고**: 이건 키, 체중, 성별 데이터를 저장하기 위한 기능이야.

## V2. 메인뷰
- **목적**: 앱 실행을 했을때 보이는 메인 화면
- **필요 기능**:
  - 지역별 추천 코스 데이터 리스트 보내주기
    - 지역을 선택하면 추천 코스가 나오는데 이런 지역별로 추천코스 데이터가 리스트 형태로 넘어가야함
    - 추천 코스 데이터 안에는 이름, 시간, 거리, 코스 설명 등이 들어가 있어야 함
- **필요 데이터**:
  - 지역 데이터 (군산, 전주 등등)
  - 코스 데이터 (이름, 시간, 거리, 코스 설명)

## V3. 지도뷰
- **목적**: 사용자가 코스를 직접 생성하기 위해 정보를 얻는 지도 뷰
- **필요 기능**:
  - 지도에 들어갔을 때 기본적으로 보여줄 관광지, 음식점, 편의시설 리스트 보내주기
  - 현 위치 기반에서 가까운 추천 관광지, 추천 음식점 리스트 보내주기
- **필요 데이터**:
  - 관광지, 음식점, 편의시설 등 장소 정보 및 좌표 리스트
  - 현 위치 기반 추천 관광지, 추천 음식점 데이터 리스트
- **연동/비고**: 위치 기반 관광 정보 조회 API, 소개 정보 조회 API, 반복 정보 조회 API, 공통 정보 조회 API, 사진 API 
  - 위치 기반 관광 정보 조회 API를 통해서 받아온 데이터들을 나머지 4개의 API를 활용해 상세 데이터까지 뽑아와야함

## V8. 코스 확인뷰
- **목적**: 경로 수정뷰에서 저장한 코스를 확인하기 위한 뷰
- **필요 기능**:
  - 경로 수정뷰에서 저장한 지도 마커 json 데이터 가져오기
  - 근처에 있는 편의 시설 정보 가져오기
  - 관광지 좌표 데이터 가져오기
- **필요 데이터**:
  - 지도 마커 json 데이터
  - 근처에 있는 편의시설 데이터
  - 관광지 좌표 데이터
- **연동/비고**: 위치 기반 관광 정보 조회 API, 소개 정보 조회 API, 반복 정보 조회 API, 공통 정보 조회 API, 사진 API

  - 관광지는 그냥 크게 뭐 군산이면 군산에 있는 관광지 데이터 가져와야 할 것 같음

## V10. 완주 결과뷰
- **목적**: 완주하거나 중단했을 때 보여주는 화면으로 근처에 있는 것들도 함께 보여줌
- **필요 기능**:
  - 완료한 러닝 데이터 저장
  - 완료 지점 근방 500m 내에 편의시설, 음식점, 관광지 보여주기
- **필요 데이터**:
  - 완료한 러닝 데이터 저장
  - 코스 완주율 데이터 저장
  - 완료한 코스 경로 데이터 저장
  - 완료한 러닝 통계 데이터 저장
  - 공유용 결과 데이터 저장
  - 완료 지점 근방에 관광지 데이터 리스트
  - 완료 지점 근방에 편의시설 데이터 리스트
  - 완료 지점 근방에 음식점 데이터 리스트
